# @sejour/socle

Socle partagé des sites de location saisonnière : [Albiez](https://albiez-aiguilles.fr) et
[Coliving Barbusse](https://www.coliving-barbusse.fr).

Pas de build : le paquet expose du TypeScript brut, compilé par Next dans l'application via
`transpilePackages`.

```jsonc
"@sejour/socle": "github:colivinglemans-prog/sejour-socle#v0.1.0"
```

Conventions, règles d'admission et feuille de route : voir [CLAUDE.md](CLAUDE.md).
